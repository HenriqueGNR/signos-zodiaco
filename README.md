# Signos do Zodíaco - Versão JavaScript/HTML

Esta é uma versão convertida do aplicativo original, agora totalmente implementada em JavaScript e HTML, sem uso de PHP, permitindo hospedagem em GitHub Pages.

### Tecnologias Utilizadas

- **Eliminação completa do processamento server-side**: Toda lógica PHP foi convertida para JavaScript no lado do cliente
- **Dados dos signos em JSON**: Substituição do arquivo XML por dados JSON embutidos no JavaScript para melhor performance
- **Interface responsiva aprimorada**: Uso do Bootstrap 5 para design moderno e responsivo
- **Compatibilidade total com hospedagem estática**: Funciona perfeitamente em GitHub Pages, Netlify, Vercel e outros serviços similares

### Funcionalidades

- Consulta de signo zodiacal a partir da data de nascimento
- Interface simples e amigável
- Informações detalhadas sobre cada signo
- Design responsivo para dispositivos móveis

## Tecnologias Utilizadas

- **JavaScript** - Lógica de processamento e manipulação DOM
- **HTML5** - Estruturação semântica do conteúdo
- **CSS3** - Estilização personalizada
- **Bootstrap 5** - Framework CSS para design responsivo

## Como executar

### Hospedagem Local
1. Clone o repositório
2. Acesse a branch `html-js`: git checkout html-js
3. Abra o arquivo `index.html` diretamente no navegador

### Hospedagem em GitHub Pages
1. Faça push da branch `html-js` para o repositório
2. Configure GitHub Pages para usar a branch `html-js`
3. Acesse o site através da URL fornecida pelo GitHub Pages

### Hospedagem em Outros Serviços
O projeto é compatível com qualquer serviço de hospedagem estática, como Netlify, Vercel, ou Surge.

## Diferenças da Versão Original (PHP)

- **Sem necessidade de servidor PHP**: Funciona como site estático
- **Dados embutidos**: Não depende de arquivos XML externos
- **Melhor UX**: Interface mais fluida e responsiva
- **Hospedagem gratuita**: Compatível com GitHub Pages
- **Performance**: Carregamento mais rápido

**Nota**: Esta versão foi desenvolvida como parte do relatório de aula prática da disciplina de Programação Web (5º Semestre), convertida para permitir hospedagem gratuita em serviços de hospedagem estática.
